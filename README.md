- 各版本内的测试报告保留原有内容；它们不能自动视为当前抖音页面的真实发送验收。
- v0.5.1 的 variants/ 中保留了工作区的同版本变体；其 SHA-256 与该版本 ZIP 内发布脚本不同，因此单独归档。
