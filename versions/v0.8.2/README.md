# 抖音火花助手 V0.8.2

这一版移除一键发送后的人工核对流程。点击“一键自动发送”后，脚本自动切换会话、输入、尝试发送并检查结果：观察到新增的同文己方消息且编辑器清空时显示“网页已确认发出”；证据不足时显示“发送结果未知”并停止，不要求点击人工核对按钮，也不会重复提交。

**Build ID**：`v082-auto-result-no-manual-20261009-r1`

## 安装

在 Tampermonkey / ScriptCat 中用 `douyin-spark.user.js` 更新旧脚本。只启用一个版本，刷新抖音聊天页后到“高级”确认 Build ID。脚本为正常排版的多行文件，可直接从文件完整复制。

## 验证范围

隔离 Chromium 测试覆盖 Enter 发送成功与页面忽略 Enter 两种情况。后一种情况没有人工核对按钮、没有第二次提交。本版仍未在真实抖音上进行新一轮发送验收；不能把隔离测试视为真实发送成功。

历史 `manualChecks` 数据保留在备份和迁移结构中，界面不再读取它来要求人工确认。旧版未确认的发送意图继续阻止同日重复提交。

没有启用定时任务，没有在真实抖音发送，没有 push。
