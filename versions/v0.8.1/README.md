# 抖音火花助手 V0.8.1

这一版从用户提供的 V0.8.0 源码出发，只调整真实发送动作。输入框、会话核对、当日防重复记录、成功判断和现有界面保留。

发送动作参考提供的另一份续火脚本：对已聚焦的抖音编辑器派发 Enter 的 `keydown`、`keypress`、`keyup` 事件。每次提交只使用这一种动作；若没有观察到新增己方消息及输入框清空，状态保持“消息待核对”，不会改用按钮点击或自动重试。

**Build ID**：`v081-editor-enter-20261009-r1`

## 安装

在 Tampermonkey / ScriptCat 中用 `douyin-spark.user.js` 更新原脚本，并确保同一页面没有同时运行两个版本。脚本已经排版为 2,226 行；请从这个文件复制完整内容，不要复制聊天中被压成一行的文本。刷新后到“高级”确认 Build ID。当前真实 Chrome 仍运行 V0.8.0；V0.8.1 尚未在抖音上提交消息验证。

当前 Chrome 的聊天输入框已有草稿，且此前存在一次发送结果不明的记录。先处理官方聊天记录和草稿，再决定是否更新并进行新的单次验收。不要直接重复发送相同消息。

## 验证范围

`python tests/browser-send-path.py` 在隔离 Chromium 页面检验：旧版点击 SVG 父级无效；新版编辑器 Enter 只尝试一次；页面忽略 Enter 时保持 UNKNOWN。模拟页面只验证执行路径，不证明真实抖音一定接受合成键盘事件。

没有启用定时任务，没有在真实抖音发送，没有 push。
