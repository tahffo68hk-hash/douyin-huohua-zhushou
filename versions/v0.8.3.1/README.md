# 抖音火花助手 V0.8.3.1

**Build ID：** `v083-real-navigation-svg-send-20261009-r2`

这一版针对真实 Chrome 中发现的两处失败修改一键发送链路：

1. 列表会话点击后若标题没有切换，按抖音当前页面的“搜索 → 精确匹配联系人 → 发消息”路径进入，并再次核对聊天标题与选中会话。
2. 文本写入后定位同一输入区域内唯一可用的 `svg.e2e-send-msg-btn`，只向该控件派发一次点击；不再用合成 Enter 作为发送动作。

只有页面新增同文的己方消息且输入框清空，才标记“网页已确认发出”。提交动作之后若结果未知，脚本停止且不重试。发送失败的具体阶段会保留在面板中，不再被笼统提示覆盖。人工核对按钮仍已移除。

## 安装

在油猴/ScriptCat 的脚本编辑器中打开已安装的“抖音火花助手 · 一键续火”，将全文替换为本包的 `douyin-spark.user.js`，保存并刷新抖音聊天页。只启用一个版本；在“高级”确认 Build ID 末尾是 `r2`。仅更新电脑上的文件不会更新油猴内已安装的副本。文件是正常排版的多行 JavaScript。

## 验证范围

真实 Chrome 只读检查确认当前 V0.8.2 的执行记录多次显示“比比机：聊天标题与目标不完全一致”；页面实际存在唯一的“比比机”聊天标题、空 Slate 编辑器、`svg.e2e-send-msg-btn` 和官方搜索结果中的“发消息”控件。另一次发送阶段记录为“页面未确认新增己方消息”。

隔离 Chromium 测试覆盖搜索回退、SVG 点击后成功、SVG 点击无响应后的 UNKNOWN 且不重复点击。真实 Chrome 单会话验收已通过：在只勾选“比比机”、正文为“【测试】续火🔥”时，通过脚本按钮执行一次，页面出现一条同文己方新消息，编辑器清空，面板显示“已确认 1”。这证明本次网页发送链路 PASS；不代表收件人已读或官方火花天数已更新。

第一次真实 Chrome 点击 r1 脚本时，点击事件构造里的 `view: window` 因油猴隔离环境转换失败，在切换会话前抛错；没有到达发送控件，也没有提交消息。r2 已去掉该参数，并把这种提交前异常正确标为“未发送”。随后 r2 在真实页面完成上述单次验收。
