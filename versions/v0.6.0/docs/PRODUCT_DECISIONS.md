# Sol 审核结论落实清单

审核结论（产品输入）：14 个导航 → 今天＋设置；以手动辅助为主；64 项细分能力中 28 项删除、12 项合并、12 项简化。这里记录新标准版对该决策的落实方向，不声称逐项审计源码与历史功能数量重新核实。

| 决策 | V0.6.0 |
|---|---|
| 两个一级区域 | 今天、设置 |
| 聊天筛选、处理名单 | 今天：添加聊天抽屉、状态筛选、处理/跳过/撤销 |
| 内容、素材、预览 | 单一最终正文框，常用内容抽屉，复制即快照 |
| 正式发送路径 | 用户自行使用抖音官方聊天框；脚本无发送动作 |
| 原生表情 | 使用抖音官方工具栏；移除实验性发送脚本 |
| 每日计划、API、随机文案、逐人定时、多账号 | 标准脚本不执行；原数据快照存档 |
| 日志、诊断、统计、通知中心、高级、帮助页 | 移除原页；必要的简单提示、最小脱敏排查、3 条帮助放在设置 |
| 重燃与火花天数 | 证据不足时未知；不出现假天数、假成功 |
| 未提交/待核实任务 | 历史数据保留、冻结状态保留；复制与人工撤销不改变提交事实 |
| 备份与迁移 | 同命名空间写前快照、校验、幂等，导入预览及确认，自动发送关闭 |

没有强行实现原审核明确留给未来的稳定 ID 自动发送功能。
