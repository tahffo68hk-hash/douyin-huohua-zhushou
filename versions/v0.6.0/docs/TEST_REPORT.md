# V0.6.0 轻量版：实现与测试报告

日期：2026-10-09

基线：用户上传的 V0.5.3 脚本文本 `v053-dom-adapter-20261009-r1`、Sol 的《产品精简独立审核报告》及《Antigravity执行规格》。本环境无法访问用户 Windows `D:\douyindoubao` 目录，也无法操作其已登录的真实 Chrome；因此新版通过本地源码重写和模拟浏览器测试验收，不声称已替换原文件或完成真实账号测试。

## 已落地的产品变化

- 一级导航从 14 页重做为严格 2 页：今天 / 设置；常用内容为今天内的抽屉。
- 用户编辑文本、复制到剪贴板、在抖音官方聊天手动发送并人工核对；没有自动填写、脚本触发 Enter、群发、后台执行或消息重试。
- 旧 API/回调权限、网络文案、系统通知、定时器、随机轮换、独立计划、详细统计、脚本菜单发送/清空按钮不进入新脚本。
- 火花/重燃状态没有可靠页面证据时只显示一次“暂时无法可靠读取”；不把人工确认或复制记为平台续火成功。
- 聊天类型由可见结构推断，群聊/明显 AI 默认禁加，未知类型保留人工选取；不通过昵称/头像/位置创建稳定身份。
- 原始命名空间 `spark-full:v2:` 保留；在旧联系人规范化前快照所有可枚举的旧键，并保留旧任务 UNKNOWN/SUBMITTED。迁移完成状态和写后验证保障幂等及失败关闭。
- 旧版动态模板仅存档；新默认「续火🔥」。安全备份白名单过滤嵌套凭证/日志，恢复先预览、二次确认，本机任务不被覆盖为可重试。

## 安全边界

- 未授权真实私信发送数：0（本地脚本及测试没有登录真实抖音账号）。
- 新标准脚本无 `GM_xmlhttpRequest`、`@connect`、`GM_notification`、周期性自动消息执行器。
- 旧外部 Python 服务、浏览器 Profile、Windows 计划任务不在本 ZIP 内；脚本不会删除用户电脑上已经存在的旧任务，请用户自行停用。
- 手动确认是用户可撤销的本地状态，不修改历史发送事实。历史无ID联系人仅做兼容存档，刷新后须重新选择。
- `GM_listValues` 不存在时只能枚举列出的固定旧键，数据不会清理，界面注明动态键可能未完整快照；如遇存储写入错误，新版停止进入只读报错状态。
