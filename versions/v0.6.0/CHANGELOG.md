# CHANGELOG

## 0.6.0 · 2026-10-09

- 重设产品定位为“人工处理与核对助手”，严格只保留「今天」「设置」两个一级区域。
- 今日名单从真实网页当前可见聊天中手动添加；不提供全选、自动群发、持久化昵称匹配。临时会话刷新后需重新核验。
- 文案改为“正文就是最终预览”，默认「续火🔥」，支持多行文本/Emoji、复制与常用文本，900 字限制不截断原文。
- 原生表情使用抖音官方面板；移除脚本实验性表情名称试发入口。
- 人工核对消息与发送、火花状态明确分离；历史 SUBMITTED/UNKNOWN 保守留存。
- 移除旧自动执行计时器、批量发送、网络文案 API、随机策略、回调/通知及其用户脚本权限。
- 新增原始命名空间快照及幂等迁移，关闭旧运行开关；恢复备份先预览，自动权限不恢复。
- 增加小尺寸浮层、拖动悬浮入口、键盘 Escape、常用内容 5 秒撤销、脱敏排查导出。
- 本地 Node + 合成 Chromium 测试；未测试真实抖音发送链路。
