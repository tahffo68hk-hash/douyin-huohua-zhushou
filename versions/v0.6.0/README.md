# 抖音续火助手 · 轻量手动版 V0.6.0

> 依据 2026-10-09《产品精简独立审核报告》和《Antigravity执行规格》重做。源代码依据用户提供的 V0.5.3 脚本文本，Build ID `v060-simple-manual-20261009-r1`。非抖音官方工具。

## 现在只做四件事

1. 打开 [抖音网页版聊天](https://www.douyin.com/chat)，点击右下角「🔥 续火」。
2. 在「今天」点「添加聊天」，找到要处理的人并加入今天的清单。
3. 写好一条内容（默认「续火🔥」），点「复制内容」，**由你在抖音官方聊天框核对收件人、粘贴并发送**。普通 Emoji 可直接加在文字里；抖音原生表情请使用官方聊天工具栏。
4. 亲眼看到正确聊天中今天的新己方消息后，点「我已在聊天中核对新消息」。这只记录人工核对，**不能证明火花已经续上或重燃成功**。

**「设置」**仅用于备份恢复、短帮助和脱敏排查。没有自动发送、定时、群发、后台消息重试、系统通知或外部文案接口。

## 安装与升级

- 推荐 **先在旧版的备份页导出一次旧备份**，保存于安全位置。
- 在 ScriptCat / Tampermonkey 中**停用旧版 Full**。若希望在原脚本上升级，进入原脚本的编辑页面，把旧代码完整替换为 `douyin-spark-simple.user.js`，保存。**不要让 Full 和轻量版同时运行**。
- 也可以新装脚本，但必须关闭所有旧同类脚本，以避免相互干扰。刷新抖音 `/chat` 页面。
- 首次加载会在既有 `spark-full:v2:` 命名空间内保存一份**原始数据快照**，而后新增轻量版的数据。若 `GM_listValues` 可用，将枚举旧动态键；否则标明快照枚举可能不完整，**不会删除任何旧键**。
- 首次加载以及其后每次打开都会强制将旧 `settings` 中的自动发送/回调/提醒相关开关关闭；若迁移写入失败，助手进入只读的报错状态而不会继续操作。

## 数据与恢复原则

- 历史联系人、未识别名单、任务（包括 `SUBMITTED` 和 `UNKNOWN`）、旧素材、规则、原始设置等留在旧数据/本地快照里；不会按昵称或头像自动重新绑定联系人。
- **没有稳定 ID 的今天名单只在当前页面有效**，刷新后须重新选择。即使某一项带有 ID，新版也不会将其未经核验的身份直接授权自动发送。
- 文本及 Emoji 常用内容在「今天 → 常用内容」中复用；原生表情包名称留作历史存档，不会当作可发送文字。
- 只有确认等于**旧版未改动默认模板**的内容才改为简短默认文案。自定义纯文本尽可能按原文保留；包含旧 `[API]`、`[天数]` 等占位符的动态文案仅存档、不自动调用接口或替换。
- 「设置 → 导出安全备份」是白名单导出，包含你保存的正文和历史身份名称等私人数据，请不要公开分享。会移除回调令牌等敏感键和原始日志，**不**包含浏览器 Cookie、账号 Profile、旧本地服务配置文件。
- 「导入备份」先预览再确认；确认前会保存恢复前的本地状态，恢复后不会继承自动执行权限。本地未确认/已提交的历史任务优先保留，不清除危险状态。
- **不会自动删除**你电脑上以前安装的 Python 调度程序、计划任务或浏览器 Profile。如果之前设过系统定时任务，请自行在操作系统中停用旧任务。

## 功能变化

| 原 Full 版 | 轻量版 V0.6.0 |
|---|---|
| 14 个一级导航 | 2 个：「今天 / 设置」 |
| 发送 / 文案 / 素材 / 计划四处设置 | 一个正文框 + 常用内容抽屉 |
| 批量发送与定时发送 | **移除脚本执行入口**；手动复制到官方聊天发送 |
| 火花天数与重燃推断 | 不显示未经证实的状态，不宣称成功 |
| 一言、TXTAPI、星期模板、轮换 | 移除可执行分支；旧值存档 |
| 通知、7/30天统计、复杂日志、诊断页 | 移除；保留最小的今日人工处理计数和脱敏支持包 |
| Windows/Python 多账号调度 | 不再属于新标准发行包 |

## 技术限制和验收

- 本包通过本地 Node 核心测试与**合成 Chromium** 交互测试。该模拟网页由测试脚本自行构造，**并非真实抖音**，不能证明真实账号昵称、火花标签、原生表情和消息发送适配成功。
- 没有直接连接真实抖音 Chrome，也**没有发送任何真实消息**。新版刻意不触发平台发送动作。
- 抖音可能变更聊天 DOM。无法读取的项目必须显示未知；不要用昵称相同推断为稳定身份。
- 若脚本不出现：确认旧版已停用、脚本管理器匹配到 `https://www.douyin.com/chat*`，打开控制台查看异常，必要时导出设置中的脱敏支持文件。
- 关闭浏览器或刷新页面会丢失无稳定 ID 的当前名单，但不会清空旧版的历史任务数据。

## 本地开发测试

```bash
npm run check
npm test
npm run test:browser
```

`npm run test:browser` 需要 Python、`playwright` 包及其支持的 Chromium，可在本机安装后执行。测试不会访问真实抖音账号，也不会向任何人发送私信。`tests/browser-smoke.py` 使用虚构联系人。

## 版本与回滚

版本：`0.6.0`，Build ID：`v060-simple-manual-20261009-r1`。

回滚建议：先导出 V0.6.0 安全备份，停用轻量版，重新安装之前**你自己保留的** Full 版。旧数据原键仍在；升级前的完整原始快照留在 `spark-full:v2:simple:v1:legacy-snapshot`。回滚后的旧脚本拥有原始自动执行功能，务必检查并关闭它的自动计划、回调和旧操作系统计划任务。不要通过清空浏览器数据回滚。
