# 抖音火花助手 V0.8.0 — 一键发送 + 高级模块 + 多账号调度

这是独立的 ScriptCat/Tampermonkey **单文件用户脚本**，搭配可选的 Python / PowerShell / Bash 本机工具。只操作抖音聊天网页可见元素，不读取 Cookie、密码或调用私有消息 API。

**请区分：功能已开发和隔离模拟测试通过，不等于你的真实抖音账号已经经过实发验收。** 发送结果只表示网页中观察到新增匹配的己方消息，不代表火花实际续上。

## 1. 三步开始

1. 关闭之前安装的 Full、Lite、0.6、0.7 等重复脚本；用 ScriptCat / Tampermonkey 安装唯一的 `douyin-spark.user.js`（版本 `0.8.0`，Build `v080-full-integrated-20261009-r1`），刷新 `https://www.douyin.com/chat`。
2. 点击右下角 **🔥 续火**。打开即扫描当前聊天列表；可点 **扫描全部** 滚动收集更多会话。在列表逐个勾选，或点 **全选可用**；群聊、明显 AI 会话、重名歧义项不自动勾选。
3. 在 **发送内容** 中编辑你要发送的单行文字/Unicode Emoji，点击 **一键自动发送**。**按钮点击即执行，没有额外名单确认弹窗**。脚本依次切换所选会话、检查标题与可选的当前选中行、输入内容、点击官方页面发送控件，并以新增己方消息为核验依据。进度和待核对记录留在页面。

在真实页面第一次使用时，建议**先选一位同意测试的联系人**，确认输入、发送、记录正常，再使用多会话模式。适用的目标应是你有权联系且愿意接收的聊天对象。

### 核心发送边界

- 页面必须打开且可见，正常登录，支持 Web Locks。不启动无人值守的私有接口机器人。
- 每轮最多30个选中会话（超过后要求分轮）。**不强制要求每位都有稳定 ID**；但需要逐人唯一的精确昵称/类型、点击后聊天标题及可见选中状态不冲突。有歧义直接停在该位，不继续盲发。
- 当前编辑器存在草稿，或目的聊天、发送控件无法核验时停止；**绝不清除/覆盖已有草稿**。
- 结果不明确时写 `UNKNOWN`、停止队列、**不自动重发**。防重复发送意图在本地存储，刷新后同一天同对象同内容仍被拦截。
- 只允许1～900字的单行文字自动发送；多行内容可复制到官方聊天手动发送。
- 默认没有后台定时发送，必须从高级模块明确开启。浏览器休眠、页面不在前台、平台改版或登录态失效会影响定时。

## 2. 高级功能（按需勾选，日常工作台不堆设置）

点击「高级」→「管理高级功能」，勾选后相应模块在高级或今天区域出现。

| 模块 | 作用 |
|---|---|
| 常用文案库 | 收藏、复用、删除文字/Emoji |
| 快捷 Emoji | 主编辑器四个快速插入按钮 |
| 执行记录 | 查看最近记录、按昵称/状态/原因筛选、导出 JSON |
| 备份与恢复 | 导出、导入预览、确认恢复；不会自动恢复旧后台任务 |
| 脱敏诊断 | 导出不含姓名、消息、ID值、凭证的结构摘要 |
| 火花状态读取 | 有页面 DOM 证据时在列表/当前会话显示官方读数 |
| 自定义发送间隔 | 顺序发送之间等待 1～30 秒 |
| 批量内容轮换 | 从保存的文字中顺序选择本轮每个收件人的正文 |
| **每日定时执行** | 自定义一个时间、宽限窗口、保存当次勾选名单，前台运行一次 |
| **安全失败重试** | 只重试**提交前的定位失败**；提交后不明绝不重发 |
| **火花天数管理** | 采集可见数字，或手工编辑明确标记为本地记录 |
| **多账号调度联动** | 本机回调服务器和独立浏览器 Profile 的账号映射 |

`火花天数管理` 中的手工数值是 **本地记录**，不是抖音官方当前状态；页面抓取的数字也可能随页面变化，均不能单凭发送结果推算“续火成功”。

### 设每日定时

1. 「今天」先勾选需要处理的聊天。
2. 「高级」→管理高级功能→勾选 **每日定时执行**。
3. 设置本机 `HH:MM`，点击 **保存当前勾选为定时名单**，最后勾选 **启用定时**。

到指定时间且网页处于前台、已登录、未暂停时，脚本扫描并逐位核对，**无需再次确认弹窗**。每天首次到点会先登记“本日已触发”，崩溃或结果不明不自动重试；可在高级关闭定时。旧版留下的自动计划、随机时窗等不会被偷偷启动。

> 定时名单依据当时明确选择的昵称、类型及可用稳定 ID 存档，**不会把昵称升级为稳定 ID**；若改名、重名、类型变化或当前页面无法唯一核验，运行会停止。不要把这作为 100% 可靠的后台闹钟。

### 暂停/恢复

「高级」→「暂停一键发送 / 恢复一键发送」。保留暂停状态，重新加载仍生效。

## 3. Windows / Linux/macOS 多账号

配套文件在 `tools/`，**可选**；单账号只安装用户脚本就能使用。

每个账号使用不同的**本地 Chrome Profile 目录**。不会保存抖音密码，不复制登录凭证；首次必须自己在各 Profile 登录、安装并启用 ScriptCat/Tampermonkey 和本脚本。

### 账号配置（推荐 Windows GUI）

```powershell
cd tools
python manager.py --init    # 第一次创建 config.json 和随机回调密钥
python manager.py          # 打开 Tkinter 图形管理器
```

在管理器填账号标识、浏览器命令或可执行文件路径、独立 Profile 路径、每日启动时间和回调端口。保存时 `config.json` 包含本机密钥，**不要上传、分享或提交到 Git**。

### 给每个 Profile 的脚本配置回调

打开该 Profile 的抖音聊天页：

1. 脚本「高级」开启 **每日定时执行**，保存该账号自己的选择名单，设置与调度器一致的执行时间并启用。
2. 开启 **多账号调度联动**，填 `config.json` 中该账号标识、相同端口以及本机回调令牌，勾选完成后回调。
3. 当 Profile 被调度器打开，脚本在前台运行并以 HTTP POST 向 **127.0.0.1** 上报状态；调度器等待当前账号后继续下一个。回调只含账号标识、状态、计数与时间，不含昵称或正文。

本机 Python 回调服务仅绑定 `127.0.0.1`，每次请求通过共享随机令牌认证，拒绝过期回调和无效账户数据。不用于抖音消息发送。

### 开始调度

Windows：

```powershell
cd tools
./scheduler.ps1 -Mode once     # 立即依次启动（仍需脚本定时窗口匹配）
./scheduler.ps1 -Mode daemon   # 守护至 config.json 的每日执行时间
```

Linux/macOS：

```bash
cd tools
./scheduler.sh once
./scheduler.sh daemon
```

或统一使用：

```bash
python tools/scheduler.py --config tools/config.json --once --dry-run
python tools/scheduler.py --config tools/config.json --once
python tools/scheduler.py --config tools/config.json --daemon
```

- `once` 指**立即打开浏览器并等待脚本回调**，不代表忽略脚本内部的定时门禁。做手动测试应在聊天页直接点击“一键自动发送”。
- 同一账号脚本定时应与调度器的发送时间一致；后续账号如果在宽限窗口以外才启动，将不会发送，只会导致回调超时。按账号数量合理配置错过时间宽限。
- 默认 `close_launched_browser=false`，调度器**不会关闭用户现有 Chrome**。如果自行打开收尾选项，只会尝试关闭本次启动进程，不会终止整个浏览器进程树。
- 跨浏览器与系统定时不提供绝对保证。Chrome Profile 被已有进程使用、睡眠、网络或平台交互异常都可能导致超时。

## 4. 数据兼容和升级

沿用 `spark-full:v2:` 数据前缀和 V0.6/V0.7 轻量模式的 `simple:v1:state`；首次迁移已留原始快照。V0.8 保留旧素材、历史消息记录、旧版本任务意图，旧后台计划和回调不会自动复活。新增 V0.8 的定时模块仍默认关闭，旧版用户需要主动勾选并重新配置名单。

**升级时应停用全部旧用户脚本**，避免不同版本同时扫描或发送。重新安装本版时选择唯一 `douyin-spark.user.js`，不要混装旧版 ZIP 中的脚本。

## 6. 已知真实网页验证边界

V0.7.1 的只读诊断已经证实抖音的零宽占位符和 SVG 发送按钮；V0.8 在此基础上实现完整执行和高级模块。**本次构建环境没有连接你的真实 Chrome 登录态，没有针对 V0.8 进行实际发消息或多账号真实登录验收**。隔离的 DOM 测试不能证明真实抖音网页一定允许脚本生成的点击、输入和队列操作。需要你在真实 Chrome 先进行一位联系人受控实测，才可评估是否让多人/定时真实启用。
