测试中的浏览器是隔离 Chromium，聊天对象是合成数据，按钮和气泡由夹具模拟，与抖音真实网页的不完全一致必须保留为已知风险。

`python tests/test-browser.py` 可组织全部七个场景。在本环境将多个 Playwright 场景接在同一个长任务中时曾出现工具进程超时，七项最终分别以独立 `--case` 命令通过；**不据此声称整套长任务执行器稳定通过**。运行环境约束不能当作产品成功证据。

## 不可跨越的结论边界

- `btn.click()` 后只有新增匹配的己方网页气泡可以标记 `SENT`；这仍不代表抖音火花天数增加。
- 发送前不会弹出名单或文案确认框，按钮点击就是执行授权；日常使用务必只选择明确愿意接收消息的会话。
- 若无法确认对象、网页输入状态或消息结果，当前任务会中断，不为了追求“全自动”继续盲发。
- 多账号调度由用户在各独立 Profile 亲自登录和安装脚本；本工具不导出会话 Cookie，不通过隐藏 API 发私信。
