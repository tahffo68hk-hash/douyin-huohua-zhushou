# CHANGELOG

## V0.8.0 — Full Integration

- 「今天」保留自动滚动扫描、逐个勾选、全选可用、取消全选、编辑正文和**单击直接发送**。去掉 V0.7.1 的额外 `window.confirm` 发送弹窗。
- 自动切换聊天与无稳定 ID 多人队列采用每位实时唯一姓名/类型匹配、聊天标题与选中行不冲突检查；无法确认就停止，不会通过模糊匹配继续。
- 保留 U+200B 编辑器占位符修复和真实 `svg.e2e-send-msg-btn` 的父控件点击；发送后观察新增己方消息；未知结果不重发。
- 新增对打开中的聊天草稿的**切换前保护**，防止一键队列先清除当前草稿。
- 「高级」模块管理新增每日定时、安全失败重试、火花天数管理、本机多账号回调；并保留原常用文案、Emoji、记录、备份、脱敏诊断、火花只读、发送间隔、文案轮换，共 12 个按需模块。
- 每日定时先保存明确勾选名单，在页面可见且有 Web Locks 的情况下每天尝试一次；默认关闭、单日领取防重复、错过时间窗口后不补发。
- 失败重试只覆盖尚未发生消息提交的会话定位失败，绝不在结果未知时自动再发。
- 读取会话行可见火花天数并注明来源，手动编辑的天数不当作官方数据。
- 执行日志筛选和导出，本地调度器带回调令牌校验、Windows GUI Profile 管理、PowerShell/Bash 启动包装脚本。
- 旧配置/提交历史/原始快照保留；新版定时与回调不自动启用。

### 验证边界

本地核心、模拟 Chromium 和调度回调专项测试通过；未在用户真实 Chrome 执行 V0.8 的正式发送验证，因此不能对真实网页自动发送或多账号上线成功率作保证。
