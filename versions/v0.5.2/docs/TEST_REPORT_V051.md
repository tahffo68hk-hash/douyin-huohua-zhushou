# V0.5.1 历史验收记录（已脱敏，已被 V0.5.2 取代）

本文件保留 V0.5.1 的结论摘要，已移除真实联系人、聊天文本、会话标识和账号截图引用。

## 历史结论

- V0.5.1 的本地单元测试、调度器测试及当时的模拟浏览器测试通过。
- 当时真实 Chrome 页面显示版本标记 V0.5.1；当前会话身份门禁失败，未获得稳定会话 ID 匹配证据。没有输入或发送真实私信；自动发送保持关闭。
- V0.5.1 本地回归只验证了部分昵称/ID 逻辑，没有以“稳定 ID 位于会话包装祖先、星期标签为标题子节点”的完整 DOM 结构复现问题。

## 后续源码审计发现

- V0.5.1 根目录脚本与已打包脚本来自不同内容；发布 ZIP 使用了旧暂存目录脚本，稳定 ID 优先逻辑未进入实际发布文件。
- 源脚本在身份核验前先用昵称筛选候选；即使其他局部代码可读到 ID，标题不相同时也无法进入候选流程。
- 标题提取直接读取复合标题容器 `textContent`，可能把昵称与星期/日期标签拼在一起。
- 稳定 ID 只从有限的节点和后代属性读取，未沿会话包装祖先读取；旧测试未覆盖这种结构，也未要求列表选中项与聊天详情 ID 同时一致。

上述问题已在 V0.5.2 源码及合成浏览器夹具中重构验证。真实页面的实际 DOM 属性和稳定 ID 关联结果仍需安装 V0.5.2 后通过脱敏诊断确认；请参见 [V0.5.2 验收报告](TEST_REPORT_V052.md)。
