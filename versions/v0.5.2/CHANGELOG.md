# 更新日志

## V0.5.2 · 2026-10-09

- 重构会话身份验证：显示昵称与稳定会话 ID 分离，候选只按精确 ID 匹配；列表行、聊天详情区域及明确路由 ID 交叉核对，任何 ID 或会话类型冲突都阻止核验。
- 修复复合标题读取：昵称从最小文本节点提取，按日期/时间语义跳过周日等时间标签，不全局改写昵称文本。
- 旧配置首次迁移后标记为未核验、关闭自动发送；旧临时昵称 Key 与导入联系人不会静默升级为稳定身份。刷新只恢复有证据的 V0.5.2 关系，并在每次发送时重新核对当前页面。
- 文字和表情发送共用身份门禁；对可见聊天记录中完全相同的己方文本先阻止发送并记为 UNKNOWN；UNKNOWN/SUBMITTED 不自动重试。
- 新增脱敏 DOM 结构诊断与 `BUILD_ID=v052-idproof-20261009-r1`，以及端到端合成浏览器身份回归。
- 当前真实 Chrome 仍运行 V0.5.1；稳定 ID 是否能在列表和详情间关联仍待 V0.5.2 诊断确认。本版本没有真实私信发送证据，不建议启用自动发送。

## V0.5.1 · 2026-10-09

- 修复备份导入后的身份保护缺口：未完成稳定会话 ID 核验的联系人，不能通过手动文字发送或原生表情试发；会话列表明确显示「身份待核验」。
- 补充回归：昵称匹配不会解除门禁，匹配稳定会话 ID 才可解除；身份未核验时文字和表情路径不会切换会话或打开表情面板。
- V0.5.1 首次启动会一次性关闭旧版已保存的自动发送计划，同时保留联系人、任务历史和其他设置，避免稳定性测试启动后意外执行定时发送。
- 修复真实抖音会话列表把星期标签并入昵称后导致当前会话无法核验的问题：仅在唯一稳定会话 ID 匹配时允许核验，并用当前聊天标题校正显示昵称；ID 冲突或无稳定 ID 时继续阻止。
- 修复本地浏览器测试把 Chromium 固定到 Linux 路径导致 Windows 无法启动的问题；默认使用 Playwright 管理的 Chromium，支持显式可执行文件覆盖。
- 修复 Windows 系统区域设置下 V0.5 浏览器测试读取下载 JSON 时的 UTF-8 解码问题。
- 保持自动发送默认关闭。真实浏览器已加载 V0.5.1；当前聊天核验仍未取得稳定 ID 匹配证据，修复尚未通过真实页面复测。本次没有真实私信发送。

## V0.5.0 · 2026-10-09

- 新增「提醒」中心：用户自定义每日检查点、提前提醒、通知去重、失败与发送结果未知通知、已读状态。
- 新增「统计」中心：最近 7/30 天本地任务统计及匿名汇总导出。
- 新增「备份」中心：数据概览、备份导出时间、备份解析预览、二次确认恢复、安全校验与重新核验身份。
- 仅在本地脚本任务观察到确认发送，不冒充抖音平台续火成功。
- 对近期详情显示的待重燃独立保留提醒，即使当天消息已发出。
- 自动发送与桌面提醒在首次升级时关闭，待用户重新开启。
- 本地任务历史保留阈值扩展至最多约 45 天，以支持 30 天统计。
- 修复恢复备份后可能立即折叠导致用户看不到结果的问题。
- 既有 V0.2-V0.4 功能和测试保留。原生表情仍属手动试发，不支持定时。
