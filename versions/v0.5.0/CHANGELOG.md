# 更新日志

## V0.5.0 · 2026-10-09

- 新增「提醒」中心：用户自定义每日检查点、提前提醒、通知去重、失败与发送结果未知通知、已读状态。
- 新增「统计」中心：最近 7/30 天本地任务统计及匿名汇总导出。
- 新增「备份」中心：数据概览、备份导出时间、备份解析预览、二次确认恢复、安全校验与重新核验身份。
- 仅在本地脚本任务观察到确认发送，不冒充抖音平台续火成功。
- 对近期详情显示的待重燃独立保留提醒，即使当天消息已发出。
- 自动发送与桌面提醒在首次升级时关闭，待用户重新开启。
- 本地任务历史保留阈值扩展至最多约 45 天，以支持 30 天统计。
- 修复恢复备份后可能立即折叠导致用户看不到结果的问题。
- 既有 V0.2-V0.4 功能和测试保留。原生表情仍属手动试发，不支持定时。
