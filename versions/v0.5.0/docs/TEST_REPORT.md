## 安全设计与遗留限制

- 自动发送默认关闭；版本升级会强制关闭已启用的 V0.2 定时设置，需要重新确认。
- 真实发送前必须核对会话、消息草稿；跨标签有 Web Locks 时才允许计划任务，自动计划需要稳定会话 ID 和活动会话的 ID 交叉验证。
- 没有可验证的消息方向或发送结果时标记 UNKNOWN，今天不再盲目重发。
- 缺乏稳定 ID、页面未暴露当前活动会话字段、存在重名或重复元素时，会拒绝/跳过自动操作。
- 页面自动化仍依赖第三方网页 DOM 和合成事件；功能可能因平台变化而失效，不能保证成功。
