# CHANGELOG

## V0.9.2 — 原版选人窗口与使用帮助视觉统一

- 仅为 `showUserSelectPanel()` 和 `showHelpPanel()` 所创建的窗口新增主题专用 CSS 类；原版两个函数的内容、事件绑定以及帮助 `HELP_TABS` 正文保持不变。
- 同步 6 套明暗主题，统一窗口、按钮、复选框、搜索框、左侧帮助分类、帮助内容卡片、表格、代码片段和滚动区域的视觉风格，优化窄屏布局。
- 没有修改发送、输入、搜索、调度、名单管理以及原版其他弹窗；旧版 UI 偏好与脚本存储继续沿用。
- 新增 `tests/test_dialogs.py`：源码拷贝/事件一致性、6 主题实际 CSS、原版选人保存、全选取消、帮助搜索与跳转、零消息发送回归。
- **帮助正文暂不更新**：待用户确认仓库及新文字后处理，保留旧操作说明是有意行为。
- 仍未在真实抖音账号实发消息，不能将本次 UI 变更视为实际发送验收。


## V0.9.0 — 改为参考项目原版发送内核 + 自有界面

- 以 `dr-190/ScriptCat-Douyin-Fire-Helper` 2026.10.02 源码为基线，不再通过 V0.8 的 `runOne`、SVG 父级点击或其层层发送限制执行。
- 主界面恢复浅色「今天 / 高级」，支持滚动扫描、勾选、全选、编辑正文、一键自动发送、显示原版执行进度、暂停恢复；无逐人确认弹窗。
- 「今天」直接调用原版 `sendMessage`，导航、输入、Enter 及队列由原版函数实现。
- 「高级」配置原版定时/重试/火花/动态模板、原版设置/日志/用户选择/帮助，增加 Emoji、文案库、轮换、发送间隔、配置导入导出、脱敏诊断和多账号联动。
- 时间调度首次安装默认关闭；原版硬编码的 3 秒冷却期保留，所以高级自定义发送间隔最小 3 秒。修复最初设置 1 秒会吞掉下一人的实际问题。
- 本机回调与包内调度器的账号、X-Spark-Token、消息状态字段对齐；默认禁用，需高级开启并配置。
- V0.8 的历史数据不清空，可在初始状态下迁移草稿及素材；不自动迁移历史提交状态或打开无人值守定时。
- `tests/test_source.py` 验证原版 11 个关键内核函数与参考快照一致，`tryFindChatInput` 仅替换可配置最小 3 秒间隔。
- 真实 Douyin 页面自动发送未经实测。保留原版的合成 Enter、乐观成功判断和昵称匹配局限，不伪称已解决。
