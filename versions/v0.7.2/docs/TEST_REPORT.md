## 根因与修复

最有证据支持的失败点是发送事件目标：V0.7.1 找到了 SVG，但由于它没有按钮祖先，代码改为点击包住 SVG 的 DIV。真实页面在该操作后没有出现己方新气泡，且正文留在编辑器。旧的模拟夹具把发送处理器绑定在父级 DIV，因此错误目标也会伪造成功，未能覆盖真实事件路径。

V0.7.2 保留原有 `button` / `[role=button]` 路径；对于无按钮祖先的 SVG，改为向 SVG 本身派发冒泡的 `MouseEvent('click')`，不点击父级 DIV。真实 Chrome 的监听器处理细节无法通过只读 DOM 直接观察，因此该改动仍是待真实验证的修复假设，不能声称已经修好线上发送。
