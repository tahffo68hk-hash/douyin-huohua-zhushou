# 抖音火花助手 V0.7.1 · 一键续火与可选高级模块

这是独立的 ScriptCat / Tampermonkey 单文件用户脚本，支持 `https://www.douyin.com/chat`。无需部署 Python、云服务或 API 密钥。

## 安装与升级

1. 先关闭旧的「火花助手 Full」「轻量手动版」等同类脚本，避免多个版本重复运行。
2. 在 ScriptCat 或 Tampermonkey 中安装包内唯一的 `douyin-spark.user.js`。如果升级原脚本，也可复制全部源码替换并保存。
3. 刷新抖音聊天页，点击右下角「🔥 续火」。首次打开会自动扫描聊天列表，必要时可以点「扫描全部」。
4. 在列表中逐个勾选聊天，输入或选择一条文字 / Unicode Emoji 内容，点击「一键自动发送」，认真核对弹出的接收方与内容后确认。
5. 脚本依次在前台切换会话。每次尝试前都会检查聊天标题、输入框草稿，尝试后观察新增的己方消息。无法确认时停止后续发送，需人工查看聊天记录。

## 使用界面

- **今天**：会话自动扫描、搜索、逐项勾选、输入文字、确认发送和逐项结果。
- **高级**：点「管理高级功能」打开独立窗口，勾选后才启用模块。共有八项：常用文案库、快捷 Emoji、执行记录、备份恢复、脱敏诊断、火花状态读取、自定义发送间隔、批量内容轮换。
- 高级功能可以随时关闭，关闭开关不会删除历史素材或记录。

## 一键发送的执行限制

- 同一轮最多处理 **10 个明确勾选的聊天**，仅在**页面可见的前台**执行，不启用后台无人值守任务。
- 页面未提供稳定会话 ID 时，每轮只允许单独处理一位联系人；要批量处理多位联系人，所有目标必须有稳定 ID。
- 遇到重复昵称、群聊、明显的 AI 分身会话、标题不匹配、已有输入框草稿或身份不明确时，将停止或跳过；不会靠相似昵称猜测目标。
- 发送前有一次明确的接收方与正文确认；只应用于你有权发送且对方同意接收消息的聊天。
- 每轮发送都需要你在前台选择并确认；不会保存发送授权，也不会后台无人值守运行。无稳定 ID 时只允许单人操作；若真实页面没有唯一可用的发送控件，脚本停止并保留当前输入，不会模拟 Enter 键继续尝试。
- 单行纯文本 / Unicode Emoji 可以参与一键发送。多行内容可以保留和复制，但不会进入批量自动发送。
- 内容提交时写入本地当日防重复记录，刷新后同一昵称、类型及文案不会自动再次提交。结果不明确时，不会自动重试。
- 一次发送被观察到新增己方消息，只表示页面发送结果；**不等于抖音火花已续上**。

## 高级功能说明

| 可选模块 | 开启后效果 |
|---|---|
| 常用文案库 | 在今天页面增加内容库入口，可保存、调用和删除本地文字 |
| 快捷 Emoji | 在文字框下方显示四个常用 Unicode Emoji 按钮 |
| 执行记录 | 在高级页显示本地逐项执行结果 |
| 备份与恢复 | 展开备份导入预览与确认恢复操作 |
| 脱敏诊断 | 下载不包含昵称、正文、凭证的结构诊断 |
| 火花状态读取 | 当页面可见 DOM 中存在火花标记时显示天数和页面状态，否则直接说明未读取到 |
| 自定义发送间隔 | 设置两个会话之间等待的 1–30 秒 |
| 批量内容轮换 | 从已存常用文字中为本轮选中的会话顺序分配文案，并在发送前逐项预览 |

不提供未验证的原生表情自动发送、后台定时群发、私有接口调用或云端托管的虚假按钮。抖音官方原生表情仍使用抖音自己的表情面板。

## 兼容与数据安全

- 延续存储前缀 `spark-full:v2:` 和 V0.6 的 `simple:v1:state`，不会在更新时抹除旧配置。
- 旧版的设置、联系人、素材、任务及动态键尽可能在原位置留存、做原始快照；旧定时 / 回调开关保持关闭，不会复活。
- 只在同一个页面会话内使用昵称候选，无法可靠识别的长期联系人不会被自动保存为稳定 ID。
- 本版另有轻量的发送意图日志防止同一日相同内容意外重发；请勿自行清除浏览器脚本存储。
- 发送结果为「消息待核对」时，先在官方聊天记录核对，不要重复点击发送。

## 已验证范围与安装后的首轮验收

V0.7.1 修复真实编辑器的 U+200B 占位符误判，并识别抖音实际使用的 `e2e-send-msg-btn` SVG 控件。隔离的 Chromium 回归覆盖真实形态 DOM、历史同文气泡和未知结果停队列。另在真实 Chrome 中只读检查了当前 DOM，并在空编辑框做了不提交的输入/清除干跑；**没有点击真实发送控件或发送消息**。因此自动切换、脚本输入、真实提交和真实新增气泡仍未完成端到端实测。首次使用请先选择一个明确授权的会话和正文，单独确认一次真实发送；结果不明确时不要重试。
