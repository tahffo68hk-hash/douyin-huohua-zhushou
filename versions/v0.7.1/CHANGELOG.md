# 更新日志

## V0.7.1 — 真实编辑器输入与发送控件修复

- 忽略抖音编辑器边界的 U+200B 占位符，避免把空输入框误判为已有草稿，也避免正文核验和发送后空框核验误报失败；只剥除边界占位符，不改正文内部字符。
- 识别真实页面的 `e2e-send-msg-btn` SVG 并点击其 HTML 父容器；删除合成 Enter 兜底。找不到唯一可用控件时，在记录提交意图前安全停止。
- 页面缺少稳定会话 ID 时，限制为每轮单独确认一位联系人；多联系人队列要求目标都有稳定 ID。
- 新增 Chromium 端到端回归：无稳定会话 ID 的单次确认、真实形态时间节点、U+200B 编辑器、SVG 发送控件、历史同文气泡和提交后结果确认。
- 修复 Windows 下测试脚本用系统默认编码读取 UTF-8 源码失败的问题。

真实 Chrome 仅完成只读 DOM 检查和不提交的输入/清除干跑；没有执行真实消息发送。请勿把本地模拟测试视为真实抖音发送验收。

## V0.7.0 — 一键发送与高级功能窗口

- 修正 V0.6 中「处理」只设置当前会话但不会执行发送的交互缺口；主工作台提供真正的一键自动切换与逐人发送队列。
- 打开工作台自动扫描，展示带勾选框的聊天列表，支持搜索与扫描滚动列表。不再要求逐人点击「添加」。
- 支持前台逐人切换目标聊天并核对精确名称，保护已有编辑器草稿。
- 支持新增己方消息证据检测；不明确时停止队列并提示人工核对；不执行盲目重试。
- 保存本地当日提交意图，刷新后限制同名、同类型、同正文重复提交；保留旧任务记录。
- 设置「今天 / 高级」两区域，高级中新增独立模块管理窗口，八项实际可用功能按需启用。
- 继承旧存储命名空间与旧配置快照；不启动旧后台计划、Python 回调和外部文案 API。
- 新增 Chromium 自动切换与消息送达模拟测试，以及草稿、错人、重复发送、未知状态的安全用例。
