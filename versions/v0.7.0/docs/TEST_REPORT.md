## 真实网页验收边界

本轮没有接入用户的真实抖音账号，也没有执行任何真实私信发送。模拟 Chromium 将「点击发送 → 新增己方消息」的行为挂在网页夹具上；真实抖音页面可能没有可识别的发送按钮，或者可能不接受脚本合成键盘事件。无法在这里证明该脚本已经可以在真实抖音页面成功批量发送，不能据此标注线上稳定可用。

## 不能被视为已完成真实验收的部分

- 真实 Chrome 的自动会话切换与消息提交/送达；
- 真实抖音页面的火花、重燃标识识别率；
- 原生表情包的网页自动发送（本版没有提供这一发送能力）。

标准脚本没有显示无功能的发送入口：真实浏览器遇到不满足页面条件时会停止并给出明确状态。启用前仍需按 README 做单对象实测。
