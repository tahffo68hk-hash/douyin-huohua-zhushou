## 重点场景

- 升级 V0.4 → V0.5 不删除已有好友/素材/任务；自动发送和新增桌面提醒默认关。
- 所有预警基于用户设定的「每日检查时间」，并不声称获取抖音平台断火截止时间。提醒窗口内最多发 1 条每日汇总；错过检查时打开页面也能补提醒。
- 最近从详情页观察到「待重燃」且未超过 24 小时，会提示人工核对；即使当日消息已确认发出，也不等于重燃成功。
- 对失败与发送结果未知分别去重提醒；系统通知不包含昵称、聊天正文、浏览器 Profile、Token。
- 7/30 天本地任务统计：确认发送、未知、失败和其他状态，不把确认发送比例写成平台续火成功率。
- 匿名统计 JSON 下载只包含日期与数量，不包含用户信息。
- 备份导出不含回调令牌与 Cookie；导入仅先预览、超限/非法备份拒绝处理；点击确认后才覆盖设置及好友；保留现有历史任务状态，关闭自动发送和提醒，并标记恢复会话需要重新验证。
- 旧版模拟聊天页面手动发送、Emoji 文本、好友计划/素材轮换、跨标签防重复逻辑回归通过。
- 本地模拟页面截图：`docs/browser-v05.png`。

## 暂未覆盖的真实世界验收

1. **没有用真实抖音账号发送消息**。无法确认线上 UI 选择器、聊天身份检测、网页改版、风控等能否适配。
2. 没有平台级火花时限接口；自设检查提醒可能与真实断火时间不一致。
3. 原生表情包自动定时发送未实现，仍只有严格的实验性手动试发。
4. 浏览器/网页关闭或休眠时不会保证发送或提醒；本地多账号调度不等于 GitHub Actions 云端托管。
5. 已有历史记录可能在旧版清理策略下不满 30 天，统计页面不会补造缺失数据。
