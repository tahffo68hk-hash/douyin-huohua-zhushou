## 缺陷发现与关闭

### 已关闭：P1 备份导入身份门禁缺失

- 复现：导入没有稳定会话 ID 的备份联系人后，旧手动文字路径可以继续定位并发送；旧表情试发路径也未统一拦截。
- 修复：文本和原生表情试发共用身份就绪检查，在定位会话、打开表情选择器或发送之前阻止未核验联系人；会话行显示「身份待核验」。
- 放行条件：只有详情核验能以匹配的稳定会话 ID 确认当前会话时，才清除该标记。仅昵称匹配不足以解除门禁。
- 回归：本地专项夹具确认两条发送路径在门禁生效时不切换会话；昵称路径保持阻止，稳定 ID 匹配路径解除门禁。
- 状态：`CLOSED (LOCAL)`；未在真实抖音页面验收。

### 已关闭：V0.5.1 首次启动可能继承已开启的计划

- 风险：V0.5.0 已迁移过提醒设置时，V0.5.1 更新可能沿用已保存的 `autoEnabled=true`。
- 修复：新增一次性 V0.5.1 迁移，将自动发送关闭并保留联系人、任务历史、模板和其他设置。
- 回归：独立测试用例模拟已完成 V0.5 升级但自动发送仍开启的存储状态，验证启动后自动发送关闭且现有数据保留。
- 状态：`CLOSED (LOCAL)`；真实账号存储未更改。

### 已关闭：Windows 浏览器测试启动器不可移植

- 复现：原四个浏览器测试把 Chromium 可执行路径固定为 Linux 路径，Windows 环境无法启动。
- 修复：默认使用 Playwright 管理的 Chromium；允许经校验的 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 覆盖；Linux 参数只在 Linux 上添加；下载的 JSON 使用 UTF-8 解码。
- 状态：`CLOSED (LOCAL)`；完整启动器测试 6/6 通过，完整浏览器套件最近一次 63/63 通过。

### 已复现、已本地修复：昵称混入星期标签

- 复现：真实聊天头部标题只显示联系人名，列表解析结果把“周日”一起拼入昵称；“核对当前聊天”按昵称匹配不到唯一联系人，详情流程因此保持未知状态。
- 修复：当前聊天匹配可使用唯一稳定会话 ID；只有当前选中行 ID 或标题 ID 与联系人稳定 ID 相等时才允许核验，并将显示昵称更新为聊天标题。ID 冲突、重复昵称以及严格核验时 ID 缺失仍拒绝。
- 回归：V0.5.1 Node 用例先对旧逻辑失败，再验证稳定 ID 匹配、ID 冲突阻止以及当前聊天昵称校正通过。
- 状态：`CLOSED (LOCAL) / BLOCKED (LIVE IDENTITY)`；真实页面尚未产生稳定 ID 匹配成功证据。

### 未关闭：真实页面集成与发送证据

- 当前真实页面加载了标记为 V0.5.1 的面板；替换重启后仍无法核验目标身份，故真实火花/重燃状态、会话类型、真实表情和发送链路仍未验收。
- 用户确认已替换脚本，真实页面也记录了新的 V0.5.1 启动；但替换后针对比比机的身份核验仍失败，当前页面没有可匹配稳定 ID 的成功证据。浏览器策略不允许检查 Tampermonkey 管理页，无法独立核实安装文件内容。
- 本轮未输入或发送消息。用户限定一个测试会话并确认单条测试文案；当前身份状态未知，门禁正确阻止发送，真实发送验收保持 `BLOCKED`。
- 没有 P0 问题被本地测试或只读复查证实；由于真实修复和发送链路尚未复验，不能据此声明线上无 P0/P1 风险。

## 已知风险与建议

- **不建议开启每日自动发送。** 当前脚本未经真实页面只读核对和受控发送验证，保持默认关闭。
- 原生表情包定时发送未实现；手动实验功能也未在真实抖音面板验证。
- 本地消息确认只说明模拟页面中观察到了新消息，不代表平台火花成功续上或重燃成功。
- 浏览器关闭、休眠、页面不可见、网络故障、验证码或平台改版都可能使任务跳过或无法确认。
